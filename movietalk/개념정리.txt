maven 기반
gradle 기반
=> 프로젝트를 관리(컴파일, 빌드, 테스트, 패키징, 의존성관리)
=> 패키징 : jar / war


    maven    |   gradle
----------------------------
 pom.xml     | build.gradle 


gradle
 - 빌드 단위 : 프로젝트 단위             
 - dependencies {....} : 프로젝트 실행을 위해서 필요한 라이브러리
    => Maven Central 접속 => 라이브러리 다운로드
    => implementation : 내부 사용
    => compileOnly : 컴파일에만 사용
    => developmentOnly : 개발할 때만

./gradlew : Gradle Wrapper
 - 로컬에 gradle을 따로 설치하지 않아도 됨

spring_boot-gradle plugin
 - bootRun : 앱을 실행
 - bootJar : jar 작성
 - dependencyManagement : 버전 자동 관리

./gradlew build : build task 실행
(1) settings.gradle 읽음 : 어떤 프로젝트를 빌드할 것인가
(2) build.gradle 실행 : 의존성 설정, task 생성
(3) 실행 : 요청한 task만 실행
    ① compileJava : *.java => *.class
    ② processResources : *.class 파일을 build 디렉토리로 복사 및 가공(application.properties(yml) 환경들을 읽어서 반영)
    ③ test : test 실행
    ④ jar / bootJar => 서비스 가능한 파일 생성

./gradlew compileJava
./gradlew classes : compileJava + processResources
./gradlew test : compileJava + processResources + test => @Test 어노테이션 메소드 실행
    => JUnit 실행
    => @Transactional / @SpringBootTest / @Autowired : SpringBoot가 처리

./gradlew bootJar : 실행 가능한 jar 생성(필요한 라이브러리를 전부 포함 + 내장 TomCat)
    java -jar 파일명

./graldew build -x test : test 제외하고 build

./gradlew bootRun : compileJava + classes +  내장 tomcat 띄우고 main 클래스 실행
    => jar 생성은 안함(개발 중 실행 테스트)

./gradlew clean : lib 제거

./gradlew clean build : clean + build
